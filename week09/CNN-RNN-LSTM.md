### CNN 정리 

일반적인 Dense 층이 이미지의 공간적 구조 정보를 파괴하며 처리하는 한계를 극복하기 위해 고안되었다.
 
이미지를 1차원으로 펼치지 않고 2차원 평면 그대로 처리하여, 픽셀 간의 인접성 및 공간적 특징을 보존한다.

Convolution(합성곱)은 작은 크기의 필터(Filter)가 이미지를 훑으며 특징을 추출하여 데이터의 핵심 정보를 담은 특성 맵(Feature Map)을 생성한다.

필터 공유는 동일한 필터가 이미지 전체 영역을 순회하며 학습하므로, 대상의 위치가 바뀌어도 동일한 특징을 인식하는 능력이 뛰어나다.

Padding는 이미지 가장자리에 0 등을 채워 넣어 입력 데이터의 크기를 유지하고 외곽 정보가 유실되는 것을 방지한다.

Stride는 필터가 한 번에 이동하는 간격을 의미하며, 이를 통해 출력 데이터의 해상도와 연산량을 조절한다.

Pooling은 추출된 특성 맵의 크기를 줄이는 과정으로, 주로 Max Pooling을 사용해 가장 강한 특징만 남기고 사소한 변화를 무시한다.

모든 픽셀을 연결하는 대신 국소 영역만 연결하므로, 학습해야 할 가중치(Weight)의 개수를 획기적으로 줄여준다.

신경망의 초반부는 단순한 선이나 면을 찾고, 깊어질수록 형체나 사물의 일부 같은 복잡한 고수준 특징을 포착한다.

- 주로 이미지나 영상 처리에 최적화된 모델이다. 사람이 사진을 볼 때 코, 입, 눈 등의 특징을 잡아내듯, CNN도 이미지의 부분적인 특징을 추출한다.
- 핵심 원리 : 이미지의 작은 필터(커널)를 슬라이딩하며 데이터의 특징을 찾아내는 합성곱 과정을 거친다
- 특징 : 이미지의 공간적인 구조(어느 픽셀 옆에 어떤 픽셀이 있는지)를 잘 유지하면서 학습
- 용도 : 얼굴 인식, 자율주행 자동차의 사물 인식, 의료 영상 진단 등


### RNN 정리 

RNN은 데이터의 순서가 중요한 텍스트, 시게열, 음성 데이터를 처리하기 위해 설계되었다.

현재 단계의 연산에 이전 단계의 출력값을 다시 입력으로 사용하는 루프 구조를 가진다

과거의 정보를 압축해서 들고 있는 ‘기억 소자’ 역할을 하며, 매 단계마다 업데이트 된다

CNN이 공간적으로 가중치를 공유한다면, RNN은 모든 시간 단계에서 동일한 가중치를 반복 사용해 효율성을 높인다

입력 데이터의 길이가 제각각이어도( 짧은 문장/ 긴 문장) 유연하게 처리할 수 있다.

장기 의존성 문제 : 데이터가 길어질수록 앞쪽의 정보가 뒤로 갈수록 희미해지는 현상이 발생한다.

기울기 소실/ 폭주 : 역전파 과정에서 가중치를 반복해서 곱하다 보니, 정보가 사라지거나 너무 커져 학습이 어려워지는 고질적인 문제가 있다

Many-to-Many /  Many-to-One : 입력과 출력의 형태에 따라 번역, 감성 분석 등 다야한 구조로 변형이 가능하다.

RNN의 기억력 문제를 해결하기 위해 ‘게이트’ 개념을 도입한 발전된 형태가 주로 사용된다

단순한 개별 데이터가 아니라 앞뒤 문맥을 통해 정보의 의미를 파악하는 것이 최종 목적이다.

- 시계열 데이터나 자연어처럼 ‘순서’가 중요한 데이터를 다룰 때 사용한다. ‘안녕’ 다음에 ‘하세요’가 오는것처럼 이전의 정보를 기억해서 다음 출력에 영향을 준다
- 핵심 원리 : 정보가 바퀴처럼 순환하는 구조이다. 과거의 정보를 현재의 입력과 함께 처리하여 맥락을 파악한다
- 단점 : 문장이 길어지면 앞부분의 정보를 잊어버리는 ‘ 장기 의존성’ 문제가 발생한다
- 용도 : 간단한 문장 번역, 주가 예측 등

### LSTM 정리 

단순 RNN이 긴 데이터를 처리할 때 앞부분 정보를 잊어버리는 문제를 해결하기 위해 고안되었다.

정보를 가로질러 전달하는 ‘컨베이어 벨트’ 역할을 하며, 과거의 중요한 정보를 손실 없이 끝까지 전달한다.

정보를 무조건 수용하는 대신, 3개의 게이트를 통해 정보를 선별적으로 저장하거나 삭제한다.

과거의 정보 중 더 이상 필요 없는 것을 얼마나 버릴지 결정하는 첫 번째 단계이다.

현재 들어온 새로운 정보 중 어떤 것을 셀 상태에 저장할지 결정한다.

업데이트 된 셀 상태를 바탕으로 최종적으로 어떤 값을 외부로 출력할지 결정한다

셀 상태 덕분에 역전파 시 기울기가 급격히 작아지는 것을 막아주어, 매우 긴 문장도 학습이 가능해진다

단순 RNN보다 게이트 구조가 복잡하기 때문에 학습해야 할 가중치와 연산량이 더 많다

데이터의 긴 흐름 속에서 정말 중요한 사건이나 맥락을 포착하는 능력이 뛰어나다

자연어 번역, 긴 동영상 분석, 복잡한 주가 패턴 분석 등 현대 딥러닝 시계열 처리의 표준이 되었다

- RNN의 치명적인 단점인 ‘ 금방 잊어버리는 문제’를 해결하기 위해 등장
- 핵심 원리 : 내부에 ‘Cell State’라는 일종의 컨베이어 벨트를 둔다. 여기에 3가지 게이트를 설치해 정보를 조절한다
- Forget Gate : 쓸모없는 과거 정보는 버리고
- Input Gate : 새로운 정보 중 중요한 것만 저장하며,
- Output Gate : 어떤 정보를 밖으로 내보낼지 결정한다.
- 특징 : 긴 문장이나 긴 시간 동안의 데이터에서도 중요한 정보를 끝까지 잘 기억한다
- 용도 : 긴 텍스트 번역, 음성 인식, 복잡한 시계열 예측 등..
